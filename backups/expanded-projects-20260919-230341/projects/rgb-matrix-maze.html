Maze.

From controller input to a game on a 32×32 RGB panel.

A laptop-connected maze project using a DualShock 4 controller and an RGB panel housed in a custom 3D-printed enclosure.

GitHub · Coming soon
S

Situation

Bring a game onto a physical display

For our CPRE 1860 team project, we used a laptop-centered setup to connect a DualShock 4 controller with a 32×32 RGB panel. The panel sat inside a custom 3D-printed housing.

T

Task

Build the input bridge

I wrote the C parser and contributed to portions of the game source code. My role focused on translating controller input into commands the game could use.

A

Action

Turn input into movement commands

My parser read controller data on the laptop, applied a joystick dead zone, and sent left or right commands over a 9600-baud serial connection. I also contributed to the game code, which used red obstacles, a green player, collision checks, and timed downward movement. The display code used Adafruit graphics and RGB matrix libraries.

R

Result

A controller-to-game interface

My contribution provided the laptop-side command bridge and part of the game logic for the team’s RGB maze project. It connected text-based input processing with serial communication and the game’s movement system.
